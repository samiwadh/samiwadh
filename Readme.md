## 🔬 Research

- **Accuracy Is Not Attention: Grad-CAM Lesion Localisation Across Medical Imaging Domains** *(sole author, under major revision)*
  Trained ResNet50 (3 seeds) on 5 public medical imaging datasets across 4 modalities and evaluated Grad-CAM explanations against expert annotations (IoU, pointing game, bootstrap confidence intervals). Found that a brain MRI model with 0.880 balanced accuracy placed only ~4% of its attention on the tumour. Identified and corrected a spurious effect in my own preliminary pipeline.

- **Explainable Brain Tumor MRI Classification (Grad-CAM)**
  Deep learning medical imaging project using EfficientNetB0 with Grad-CAM explainability and targeted misclassification analysis to improve model interpretability.
  👉 [View on Kaggle](https://www.kaggle.com/code/samiwadho/explainable-brain-tumor-classification-grad-cam)

- **Global & Italy SDI Analysis (1950–2021)**
  Time-series analysis and forecasting of socio-demographic development indicators using statistical methods and visualization techniques.
  🏅 Selected for publication on [DataPitch](https://datapitch.it/#pdf/global-burden-of-disease-to-sdi-analysis-socio-demographic-index-trends-19502021), curated by Prof. Andrea Nelson Mauro (University of Milano-Bicocca).

- **Knowledge Graph-Enhanced RAG for Academic Question Answering**
  Curriculum-based question answering system combining Retrieval-Augmented Generation (RAG) with a Knowledge Graph to improve contextual and academic reasoning over course PDFs (University of Milano-Bicocca).

- **ML Classification of Spine Health for Predicting Lower Back Pain**
  Machine learning project using biomechanical spinal features and multiple classifiers (Random Forest, Gradient Boosting, KNN) to predict spinal condition, with SMOTE-based imbalance handling.

- **Mental Health Data Integration & Analysis (Global Study)**

- **Multi-source Data Integration Project (US Retail Sales & Public Holiday Analysis)**
